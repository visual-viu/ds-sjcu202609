# AI창작학과 Lucky Draw

2026 세종사이버대학교 한마음축제 AI창작학과 럭키드로우입니다.

## 페이지
- `/` 메인
- `/draw` 럭키드로우
- `/hall-of-fame` 명예의 전당
- `/admin` 운영자 페이지

## 데이터
Supabase를 사용해 상품 재고, 당첨자, 추첨 로그를 여러 기기에서 공유합니다.

## 운영자
관리자 PIN은 Vercel Environment Variable의 `ADMIN_PIN` 값을 사용합니다.

운영자 페이지에서 상품 재고 조정, 당첨자 확인, 당첨자 개별 삭제, 삭제 시 재고 복구, 전체 초기화가 가능합니다.
당첨자 일시는 날짜와 시:분:초까지 표시됩니다.

## 현재 상품
- CGV 영화 예매권 10명
- 부스트랩 생활용품 5명
- 캐릭터 굿즈 맥세이프 10명

> Environment Variable을 새로 추가하거나 변경한 경우 새 배포가 필요합니다.
